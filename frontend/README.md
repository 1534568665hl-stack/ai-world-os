# Frontend

This directory contains the React + Vite + TypeScript frontend scaffold for AI World OS.

It is intentionally minimal and only provides the structure needed for future modular development.

## Structure

```text
frontend/
  public/
  src/
    api/
    assets/
    components/
    hooks/
    layouts/
    pages/
    stores/
    types/
    utils/
  index.html
  package.json
  tsconfig.json
  vite.config.ts
```

## Status

Skeleton only. No chat interface, AI integration, memory display, world simulation, authentication, or database connection is implemented.
